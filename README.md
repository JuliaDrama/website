# 📚 Образовательная платформа с AI-ассистентом

**Интерактивное веб-приложение с внедрением искусственного интеллекта для изучения основ машинного обучения**

## 🚀 О проекте

Цель проекта — создание образовательной платформы с AI-ассистентом, который помогает студентам эффективно изучать материал, получать пояснения по выделенному тексту и взаимодействовать с системой через удобный чат-интерфейс.

Проект реализован в рамках дипломной работы в ГУАП (кафедра 41) и решает следующие задачи:

- Персонализация обучения с помощью моделей искусственного интеллекта
- Повышение вовлеченности студентов
- Увеличение доступности учебного контента и адаптация под уровень пользователя

## 🧠 Используемые технологии

- **Backend**: Python, Flask, Flask-Restful, Celery, Redis
- **Frontend**: HTML, CSS, Jinja2
- **Базы данных и кэш**: PostgreSQL, Redis
- **AI**: HuggingFace Transformers (модели T5, GigaChat)
- **DevOps**: Docker, Docker Compose
- **Логирование**: Logstash, Elasticsearch, Kibana

## 🧩 Архитектура

- `Auth API`: регистрация и аутентификация (JWT)
- `Courses API`: управление курсами, модулями, уроками и этапами
- `AI Assistant API`: генерация ответов, подсказки по выделенному тексту
- `Celery + Redis`: фоновая обработка задач
- `PostgreSQL`: основная БД
- `Yandex Object Storage`: хранение файлов
- `Logstash + Elasticsearch + Kibana`: сбор, хранение и визуализация логов

## ✨ Возможности платформы

- Регистрация и авторизация
- Страница курса с модулями, уроками и этапами
- AI-ассистент «Космокот» с диалоговым окном
- Возможность получать пояснение по выделенному тексту
- Поддержка формул и LaTeX-материала
- Интерактивный интерфейс с анимацией и подсказками

## 📦 Установка и запуск

```bash
git clone https://github.com/<your-username>/ai-learning-platform.git
cd ai-learning-platform

# Запуск с помощью Docker Compose
docker-compose up --build
```

> По умолчанию приложение доступно на `http://localhost:8000`
